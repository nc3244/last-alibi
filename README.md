# Last Alibi
An original night-shift survival mystery: monitor four cameras, question three human warehouse workers, ration security power, and survive until dawn with enough evidence to identify a murderer.

**Status:** concept / Initial G1 documents, not a playable game.
**Owner:** Nikhil Chagam — individual project; Executive Producer and Creative Director directing a planned agent team.

## The core choice
Spend an action investigating a worker's alibi, or use power to defend the security office. A turn-based night clock advances only after committed actions; AI generation never advances danger. Deterministic code controls routes, attacks, power and doors. Bounded AI changes worker testimony and defense, never crime facts.

## Proposed prototype
One short night, one office, four static cameras, three human workers, one powered door, power/clock/case-strength HUD and an evidence board. Godot 4 / GDScript plus a server-side OpenAI API; model and rates TBD. No executable game, test runner or deployed agent exists yet.

## Design references
Five Nights at Freddy's: fixed-station camera surveillance and limited-power defense. L.A. Noire: evidence confrontation. Return of the Obra Dinn: deduction records. Original setting, human characters, writing, audiovisual assets and branding; no franchise content is included and no affiliation is claimed.
